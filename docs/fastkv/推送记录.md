## 本次推送的 3 个 commit

### 1. `11566f47e` — FastKV 方案 A：捕获真实 attention
- prefill 逐层捕获 softmax 后的 kq，host 端 reduced 成真实 per-key saliency（替代旧 CPU K-近似-Q 的失真打分）
- 关键文件：`src/llama-graph.cpp`（capture 只存原始 kq + `ggml_cont`）、`src/llama-graph.h`（`t_fastkv_kq`）、`src/llama-context.cpp`（saliency readback）

### 2. `21a5754de` — 真实 saliency 驱动 compact
- 用真实 attention 分数选保留集（`fastkv_compact_from_saliency`），替换 CPU 近似打分
- 实测（远程 35B/tsp9）：Generation **27.9 vs 旧方案 24.6（+13%）**
- 关键文件：`src/llama-kv-cache.{h,cpp}`、`src/llama-context.cpp`

### 3. `c3cbad31b` — 设备端 compact + 后端自适应（本次核心优化）
- **设备端 gather**：`ggml_get_rows`（K 按列、转置 V 按扁平索引）在设备端把保留 KV 列搬到 front，替代 host memcpy round-trip
- **后端自适应**：检测 KV buffer 是否 host 后端——加速器（Metal/CUDA）走设备端 gather，CPU（`-ngl 0`）走 host memcpy
- **host fallback**：设备端 graph 构建/执行失败自动降级 host
- **通用性**：纯 ggml 标准 API（get_rows/cpy/view + sched + graph_compute），CPU/CUDA/Metal/Vulkan 通用
- 关键文件：`src/llama-kv-cache.{h,cpp}`（build_graph_compact + kv_on_device 检测）、`src/llama-context.cpp`（触发点移到 decode 循环末尾，避免 reset sched 破坏 logits）
